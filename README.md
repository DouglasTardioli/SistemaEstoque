# 📦 Sistema de Estoque

Um sistema de gerenciamento de estoque desenvolvido em **Java**, com interface gráfica utilizando **JavaFX** e banco de dados **SQLite**.

O projeto foi criado com o objetivo de praticar conceitos de desenvolvimento de aplicações desktop, organização de dados e persistência de informações em banco de dados.

## 🚀 Tecnologias utilizadas

* ☕ **Java 21**
* 🎨 **JavaFX**
* 🗄️ **SQLite**
* 📦 **Maven**
* 🧩 **FXML**

## ⚙️ Funcionalidades

O sistema permite realizar o gerenciamento de produtos e informações relacionadas ao estoque, proporcionando uma aplicação prática para controle e organização de dados.

Entre os principais recursos do projeto estão:

* 📋 Cadastro de produtos
* ✏️ Edição de informações
* 🗑️ Exclusão de registros
* 📦 Controle de produtos em estoque
* 🔍 Consulta de informações
* 💾 Persistência dos dados utilizando SQLite
* 🖥️ Interface gráfica desenvolvida com JavaFX

## ▶️ Como executar o projeto

### Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

* **Java JDK 21**
* **Maven**

### Clonando o repositório

```bash
git clone https://github.com/DouglasTardioli/SistemaEstoque.git
```

Entre na pasta do projeto:

```bash
cd SistemaEstoque
```

### Executando com Maven

```bash
mvn javafx:run
```
